LOG34970A command coverage
===========================

Source: Agilent 34970A/72A Command Reference (Docs/Agilent 34970A 72A
Command Reference.pdf), "Command Quick Reference" appendix, cross-checked
command by command against LOG34970A/LOG34970A_v2.py's storage() tree.

Legend:
  OK          command tree generates this command correctly
  EXCLUDED    deliberately not implemented (see reason) - matches the
              rf_keysight349xx Robot Framework driver's own exclusion policy
  N/A         applies to the 34972A/LAN-equipped/internal-DMM variants only,
              or to front-panel USB mass storage; out of scope for this
              RS232/USB-GPIB driver of the 34970A

See docs/scpi-driver-core.md "SCPI command coverage" for the bugs found and
fixed while compiling this table (configure.*.conf never worked, a few
commands that generated nonexistent SCPI, missing required parameters, and
a dead SENSe:TOTalize tree).

Summary
-------
Counted at the granularity of the vendor's own "Command Quick Reference"
appendix: each command/query line (e.g. "FOO" and "FOO?" count as two),
PDF line-wraps merged back into one entry each.

  360 commands documented in the Command Reference
  308 OK        (85.6% of 360)
   16 EXCLUDED  ( 4.4% of 360): CALibration (9), DIAGnostic (6),
                SYSTem:SECurity[:IMMediate] (1)
   36 N/A       (10.0% of 360): SYSTem:COMMunicate:LAN:* (20),
                MMEMory (9), INSTrument (3), LXI (4)

  308 / 324 = 95.1% of commands actually applicable to an RS232/USB-GPIB
  34970A (i.e. excluding the 36 N/A ones) are implemented. The remaining
  4.9% (16 commands) are deliberately excluded for safety, matching
  rf_keysight349xx's own exclusion policy - not an implementation gap.
